# ADR-0015: 数値は `int`(53bit安全域)+ `float` の2型

- **Status**: accepted
- **Date**: 2026-08-13
- **決定者**: ユーザー + Claude

## Context

Phase 1ラウンド3のQ12。JSの単一number型の上に、どういう数値型を見せるかを決める必要があった。

## Decision

- `int`: JSの安全整数域(±2^53-1)。`+ - *` が安全域を外れたら**panic(即時エラー)**。静かに丸めない。
- `float`: JSのnumberそのまま(IEEE 754倍精度)。
- `int / int` は切り捨て除算。floatのゼロ除算は `Infinity`(Goと同じ割り切り)。
- 暗黙変換は **int→float の拡大1方向のみ**。逆はtoInt等の明示変換。

## 検討した代替案と捨てた理由

- **単一number型(JSそのまま)**: 最もシンプルだが `1/2 = 0.5` になり、添字・件数など整数の意味論を型で守れない。
- **任意精度int(BigInt)**: 数学的には正しいが、JSのBigIntはnumberと演算を混ぜられず、FFI境界と性能のコストが大きい。

## Consequences

- 実行表現はどちらもJSのnumberで、変換コストゼロ。intの範囲検査だけランタイムに入る(演算ごとのチェックコストは将来計測)。
- 53bit超の整数が必要な用途(暗号・巨大ID)は標準外。必要になったらFFIまたは専用型を将来検討。
