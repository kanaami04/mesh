# ADR-0011: 戻り値の型はGo流(空白のみ)。アロー・コロンは使わない

- **Status**: accepted
- **Date**: 2026-08-13
- **決定者**: ユーザー + Claude

## Context

関数シグネチャの戻り値型の記法を決める必要があった。ユーザーの明確な好みとして「`->`(Rust/Swift/Python流)は使いたくない」「コロンが増えると目に痛い」がある。記号ノイズの削減は可読性研究(括弧・句読点の量が可読性を下げる)とも整合する。

## Decision

戻り値の型は閉じ括弧の後に**空白のみで置く**(Go流)。

```
fn label(id: int) string { ... }
fn find(id: int) User | none { ... }
fn log(msg: string) { ... }        // 戻り値なしは書かない
```

説明原則: 「**コロンは名前と型を結ぶ記号。戻り値には名前が無いので、型だけを置く**」。この一文を言語カードに載せる。

## 検討した代替案と捨てた理由

- **アロー `->`(Rust/Swift/Python流)**: ユーザーの好みに合わない。記号が1つ増える。
- **コロン `fn f(): string`(TS/Kotlin流)**: 「型はコロンの後」に統一できる利点はあるが、コロンの総量が増える。「名前が無いのにコロンを書く」例外とも言える。

## Assumptions

- (特になし。Go/前実装で実証済みの記法)

## Consequences

- 関数型の注釈も同じ形に揃える(例: `fn(int) string`)。
- パーサは `)` の後から `{` までを戻り値型として読む(union型 `A | B` を含む)。
- matchの腕の区切り記号(例で `->` を使ってきた箇所)は**別の未決事項**としてラウンド3で決める。
