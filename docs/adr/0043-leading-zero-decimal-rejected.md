# ADR-0043: 先頭ゼロの10進リテラルは全形(int・float・指数)で拒否する

- **Status**: accepted
- **Date**: 2026-08-17
- **決定者**: ユーザー + Claude

## Context(何を決める必要があったか)

仕様1章L-12の先頭ゼロ拒否は「先頭ゼロの10進(`0755`)」とだけ書かれ、実装も10進intの経路でのみ検査していた。そのため `0755` はE0113で弾くのに、`0755.5`・`00.5`・`01e5` は**合法のFloatとして素通り**していた(`00`=エラー / `00.5`=合法の非対称)。

MeshはJSにトランスパイルする。JS(厳格モード・ESモジュール)は先頭ゼロの10進リテラルを**整数もfloatも例外なく拒否**する。つまり現状のまま `0755.5` を受理すると、字面をそのまま出力した生成JSがSyntaxErrorになる。「ソースは合法なのに生成物が動かない」は最悪の失敗形のため、字句段階で決着させる必要があった。

実測比較(2026-08-17):

| リテラル | Go 1.26 | Rust | JS(strict/ESM) | Mesh(決定前) |
|---|---|---|---|---|
| `0755` | 493(8進) | 755 | ✗ SyntaxError | ✗ E0113 |
| `0800` | ✗ コンパイルエラー | 800 | ✗ SyntaxError | ✗ E0113 |
| `0755.5` | 755.5 | 755.5 | ✗ SyntaxError | ✓ Float |
| `00.5` | 0.5 | 0.5 | ✗ SyntaxError | ✓ Float |
| `01e5` | 100000 | 100000 | ✗ SyntaxError | ✓ Float |
| `0.5` | 0.5 | 0.5 | ✓ 0.5 | ✓ Float |

## Decision(何に決めたか)

1. 先頭ゼロの禁止を10進の**全形**(int・小数・指数)に拡張する。判定対象は**整数部**(小数点・`e`/`E` より前の数字列)で、`0` で始まり2文字以上ならE0113。spanはリテラル全体。
2. 正当な形は維持する: 整数部が `0` 1文字の `0.5`・`0e5`、`0` 単独、基数接頭辞の後のゼロ(`0x0FF`。8進誤読の余地が無いため対象外)。
3. 修正候補は `0o755` か `755` への誘導(C系8進の誤解防止)。float・指数形は先頭ゼロを剥がした字面へ案内する。
4. **不変条件**: Meshの数値リテラルは**無加工でJSに出力できる**構文のみで構成する(桁区切り `_`・基数接頭辞・指数はJSと共通構文)。字句で弾くことで、コード生成層に数値リテラルの正規化処理を置かなくてよくなる。

仕様1章L-12に注2として明文化する。

## 検討した代替案と捨てた理由

- **Go方式(非対称の現状維持)**: Goの `0755`=8進 / `0755.5`=10進float という非対称は、`0755` が「エラー」ではなく「8進という意味を持つリテラル」だから成立している。Meshは8進を `0o755` に一本化し `0755` をエラーにした時点(ADR-0030の構文採用)でGoから分岐済み。Meshの非対称はGoの模倣ではなく、L-12の適用範囲の書き落とし。
- **Rust方式(先頭ゼロ規則を撤廃し `0755`=755)**: 規則は単純になるが、`0755` を通すと字面をJSに出せず、コード生成層に先頭ゼロ剥がしの正規化が必須になる。JSトランスパイラであるMeshには合わない。
- **字句は素通しし生成層で正規化**: 実装は可能だが、正当なASTに不正リテラルが入り込む状態を作り、正規化の責務がレイヤーをまたぐ。字句で弾いた方が実装もエラー位置の品質(E0113+修正候補)も安い。

## Assumptions(この決定が依存している前提)

- A-21: Meshの数値リテラルは無加工でJSに出力できる(本ADRで登録)。

## 既存ADRとの相互作用(2026-08-14監査の教訓により必須)

- **ADR-0030(数値リテラルはフルセット)**: 「JS/Go/Rustと同等」の同等性は利用可能な構文の範囲(桁区切り・基数・指数)を指し、先頭ゼロ拒否はJS側に寄る窄小化。矛盾しない。
- **ADR-0015(int 53bit・L-11)**: 検査順はE0113が先(intの現行順と同じ。`0755e999` はE0114でなくE0113)。
- **ADR-0019(範囲 `0..n`)・L-10注(a)**: E0106(`0755.`)がE0113より先に走る現行の優先順を維持する。
- **ADR-0042(補間のトークン表現)**: 補間内の数値は同じ字句規則で再帰トークン化されるため、自動的に同一挙動になる。

## Consequences(この決定の帰結・影響)

- 仕様1章L-12に注2(適用範囲・正当形・優先順・不変条件)を追加。conformanceは `number-malformed` に負例4形(`0755.5`・`00.5`・`01e5`・`00.5e1`)と境界正例 `0e5` を加える(新IDは立てない。同一規則・同一エラーコードのため)。
- 字句解析器の先頭ゼロ検査をfloat・指数経路にも適用する。
- 将来、JSと構文が乖離する数値リテラル機能を追加するときは、注2の不変条件(A-21)ごと再検討する(正規化層の導入か、このADRの撤回かを新ADRで決める)。
