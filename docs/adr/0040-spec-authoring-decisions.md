# ADR-0040: 仕様執筆時に確定した決定の追補採録(drift-check指摘の解消)

- **Status**: accepted
- **Date**: 2026-08-15
- **決定者**: ユーザー + Claude(各決定は仕様章のspec-reviewの過程で確定済み。本ADRはPhase 1完了ゲートのdrift-checkが検出した「根拠ADRの無い決定」の採録)

## Context

仕様1〜7章の執筆・レビュー中に確定した決定のうち、6件が仕様書のみに存在しADRに収載されていなかった。決定内容の変更は無く、根拠の所在をADRに一本化する。

## Decision(いずれも既に仕様が正として確定済みの採録)

1. **ジェネリック呼び出しの常時優先解釈**(3章X-29): callee(裸またはpkg.修飾の識別子)+型引数リスト+`(` が成立する場合、比較としての合法な読みが存在してもジェネリック呼び出しと解釈する(C#方式)。
2. **名前付き関数はトップレベル限定**(5章F-1): 関数内の名前付きfn宣言は不可。再帰的ローカル関数は書けない(トップレベルへ)。
3. **fn型の戻り型は必須**(2章T-26): 型式では `fn(int) none` と書く。関数宣言の戻り値省略は `none` の糖衣。
4. **型パラメータは常に成功メンバー**(6章H-10): 失敗メンバーの分類は宣言時の型で行い、`T` は伝播対象にならない。
5. **トップレベルletのコンパイル時評価**(7章M-16): 定数式は依存順にコンパイル時評価し、panic条件該当はコンパイルエラーE0714(ADR-0038の定数式限定の評価方式)。
6. **誘導用予約語の仕組み**(1章L-7): Meshに無い機能の語(while・null・new等)を予約し、修正候補つきエラーで案内する。採録基準は白紙AI実験の実測で見直す。
