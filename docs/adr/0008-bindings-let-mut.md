# ADR-0008: 束縛は `let`(不変デフォルト)+ `mut`、シャドーイング禁止

- **Status**: accepted
- **Date**: 2026-08-13
- **決定者**: ユーザー + Claude

## Context

Phase 1ラウンド2のQ5・Q7。変数の可変性の既定と、宣言の記法を決める必要があった。

## Decision

- 宣言は `let name = 式`(不変。再代入はコンパイルエラー)と `mut count = 式`(可変)の2形。
- **シャドーイング(同一スコープ系での同名再宣言)は禁止**。「一つの名前=一つの値」を保つ。
- 型注釈は `let x: int = 0` の形で付けられる(省略時はADR-0007の局所推論)。

## 検討した代替案と捨てた理由

- **`:=`(Go風)**: 短いが、代入 `=` との見分けが1文字差。AIの学習データもGoに限られ、let系(TS/Rust/Swift)より不利。
- **シャドーイング許可(Rust風)**: 変換処理で同名を使い回せて便利だが、「どのxか」を読み手が追う負担が生じる。
- **全部可変(JSのlet風)**: 値の変化を追う負担が読み手に移り、読みやすさ方針と合わない。

## Assumptions

- (特になし。実証済みの方式の組み合わせ)

## Consequences

- レビュー・AIともに `mut` の箇所だけ注視すれば値の変化を追える。
- fmt・lintではなく**言語仕様として**シャドーイングを弾く(エラーメッセージに改名の修正候補を出す)。
