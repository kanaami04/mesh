# ADR-0018: 文字列補間は全リテラルで `${式}`

- **Status**: accepted
- **Date**: 2026-08-14
- **決定者**: ユーザー + Claude

## Context

Phase 1ラウンド4のQ14。文字列への値の埋め込み方を決める必要があった。

## Decision

すべての文字列リテラルで `${式}` の補間を使える(Kotlin風)。

```
let msg = "こんにちは、${u.name}さん(${u.age}歳)"
```

リテラルの `$` を書きたいときは `\$` でエスケープする。補間式には任意の式を書けるが、fmt/lintで長い式は変数への切り出しを促す(可読性研究の「1行あたりの識別子数」対策)。

## 検討した代替案と捨てた理由

- **専用プレフィックス(f"..." / $"...")**: 補間の有無が明示的だが、文字列の書き方が2種類になる。
- **補間なし**: 仕様は最小だが日常コードが連結だらけで冗長。UI構文のテキストでも不便。

## Consequences

- JSのテンプレートリテラル(バッククォート)と違い通常の `"` で補間できる。TS育ちのAIが `` ` `` を書いた場合はエラーメッセージで修正候補を出す。
- コード生成はJSのテンプレートリテラルへ直訳できる。
