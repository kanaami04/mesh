# ADR-0019: ループは `for` の3形のみ

- **Status**: accepted
- **Date**: 2026-08-14
- **決定者**: ユーザー + Claude

## Context

Phase 1ラウンド4のQ15。ループ構文の種類を決める必要があった。「for3形のみで煩雑になるケースはあるか」を検討し、①2変数同時更新、②逆順・非等差ステップ、③do-while、の3ケースで数行増えることを確認した上で採用した。

## Decision

```
for item in items { ... }     // コレクション反復
for i in 0..n { ... }         // 範囲(0 〜 n-1、昇順ステップ1)
for count < limit { ... }     // 条件ループ(while相当)
for { ... }                   // 無限ループ(条件省略形)
```

`while` / `do-while` / C風3節for(`for i := 0; i < n; i++`)は置かない。`break` / `continue` はある。

## 検討した代替案と捨てた理由

- **C風3節forも許可**: ①②が簡潔になるが、廃止したセミコロンが言語に出戻り、同じループの書き方が複数になる。
- **while別キーワード**: 意味は明瞭だがキーワードが増えるだけで表現力は同じ。Goが「for一本」で長期実証済み。

## Assumptions

- (特になし)

## Consequences

- ①②③はmut+条件ループ+breakで書く。逆順・ステップ付き反復は将来 `range(10, 0, -2)` 系の標準関数で解消する(構文は変えない)。
- 範囲式 `0..n` は半開区間(nを含まない)。仕様3章に明記する。
