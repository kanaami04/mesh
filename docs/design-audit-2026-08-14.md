# 設計監査 2026-08-14 — ADR-0001〜0025の相互作用レビュー

**結論: 覆す必要のある決定はゼロ。** ただし決定同士の組み合わせに16件の要対処項目を発見した。内訳: 即修正2件(修正済み)、追加決定が必要3件(ラウンド6)、仕様執筆時に規則として明文化11件。監査はClaude本体+独立レビュアー(サブエージェント)の二重チェックで実施。

## 即修正(対応済み)

| # | 発見 | 対処 |

| # | 発見 | 対処先 |

## 教訓

単体では正しい決定も、組み合わせると穴が開く(後置`?`×継続規則が典型)。以後、新ADRを書くときは「既存ADRとの相互作用」欄をテンプレに足して先回りする。
